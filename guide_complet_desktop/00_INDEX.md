# Guide complet OnDeal — Comment tout fonctionne (2026)

Ce dossier explique **tout le projet OnDeal tel qu'il fonctionne réellement aujourd'hui** : le site ondeal.fr, la boutique Shopify, les fournisseurs, le suivi client, et comment tu peux gérer les choses toi-même au quotidien.

⚠️ **Important** : le site a beaucoup évolué depuis les précédents guides du dossier `10_Guide_Comment_Tout_Refaire`. Certaines infos de ce dossier-là (logo, bandeau du haut) ne sont **plus valables** — lis `06_IMPORTANT_a_lire_avant_guides_precedents.md` pour comprendre pourquoi.

## En une phrase

Shopify est aujourd'hui **le magasin de stock/prix/produits/commandes** (le "back-office") — c'est ton outil du quotidien. Le site que voient tes clients sur ondeal.fr n'est **plus** le thème Shopify classique : c'est un site fabriqué sur-mesure, hébergé chez Vercel, qui va chercher les produits chez Shopify automatiquement. Les produits sont expédiés en dropshipping par **CJdropshipping** (fournisseur actif) ou, pour d'anciennes commandes, **BigBuy**. Détails complets dans les fichiers ci-dessus.
