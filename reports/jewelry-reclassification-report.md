## 4. Jewelry Detection Rules

- Types de bijoux détectés : ear studs, hoop/huggie/dangle/drop earrings, boucles d'oreilles, colliers, chokers, pendentifs, bracelets, bangles, charm bracelets, bagues, anklets, brooches, jewelry sets.
- Signaux matériaux (soutien, pas déclencheurs seuls) : moissanite, zircon, pearl, birthstone, sterling silver / S925, gemstone.
- **Règle critique bracelets/bagues connectés** : tout produit dont le contexte complet (titre+description+tags+productType+vendor) contient un signal électronique/connecté/wearable (connecté, smart, fitness, tracker, bluetooth, écran, montre, cardiaque, NFC, capteur, marques Xiaomi/Huawei/Garmin/Fitbit, etc.) est exclu de Bijoux, même s'il contient le mot bracelet/bague/ring.
- **Règle critique mot 'bijoux'/'jewelry' dans la description** : un produit n'est PAS classé Bijoux uniquement parce que jewelry/bijou apparaît — exclusion si le contexte indique un outil/appareil d'entretien ou de rangement (nettoyeur à ultrasons, jewelry box, organizer, pliers, etc.).
- **Cas ambigus** : titres mélangeant un objet non-bijou dominant (ex. sac à main) avec un mot bijou → confiance LOW, jamais forcés en HIGH.
